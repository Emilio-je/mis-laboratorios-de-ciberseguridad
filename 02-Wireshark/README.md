# Lab 02 - Wireshark: ICMP Traffic Analysis

## Objective

Learn how to capture and analyze network traffic using Wireshark.

The objective of this laboratory was to identify ICMP traffic, analyze Echo Request and Echo Reply messages, identify source and destination IP addresses and MAC addresses, and understand basic packet encapsulation.

---

## Tools

- Wireshark
- Windows
- Internet connection

---
